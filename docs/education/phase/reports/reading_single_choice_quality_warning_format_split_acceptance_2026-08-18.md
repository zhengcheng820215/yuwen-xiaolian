# 阅读单选质量提醒按题型分流工程验收记录

日期：2026-08-18
结论：通过

## 一、问题

结构完整、可以发布的 `single_choice` 仍会收到两条面向开放文本题的提醒：

1. 题目没有清楚说明学生需要完成的可观察动作；
2. 当前评分标准还不能清楚区分完整回答、部分回答和未达到要求的回答。

根因是质量评估器没有先按 `responseFormat` 分流：可观察动作只识别开放作答动词，区分度则统一要求至少两个 Rubric 项。

## 二、契约与工程收口

- 契约版本更新为 `reading_single_choice_response_format_v1.15` 与 `ai_resource_generation_and_optimization_workflow_contract_v1_15`；
- `single_choice` 的可观察动作改由选择语义和完整交互共同确认；
- `single_choice` 的区分度改由唯一答案、有效选项和逐项干扰依据确认；
- `short_text / long_text` 继续使用原有开放作答规则；
- 质量规则版本更新为 `question_quality_rules_v4`，已有旧版评估会被识别为过期并重新计算；
- 单选真实缺少选择动作或交互结构无效时，仍保留单选专属提醒，不以消除误报为由降低质量门禁。

## 四、验收边界

本次只修复质量检查的题型错配，不修改题目生成数量、候选采用、正式发布、Learning 投放或文本题质量规则。页面刷新或重新进入当前素材后，旧版质量结果应按 v4 自动失效并重算；合法单选不再显示上述两条文本题提醒。
