# 共享正式资源回执压缩与发布超时恢复验收记录

日期：2026-08-18

结论：通过

## 一、故障现象

《女娲造人》单选题执行“采用并发布”时，共享资源读取超过客户端时限，任务卡进入“继续发布”，并以通用 `RUNTIME_OPERATION_FAILED` 提示人工检查。

该故障与题目内容、单选质量或发布门禁无关。共享正式资源文件约 82MB，其中领域集合合计仅约 3MB，主要体积来自 Command Receipt 把完整集合 Patch 重复保存在 `fingerprint`。读取接口还为生成 `status` 重复读取和校验同一快照，最终使浏览器请求超过 3 秒。

## 二、工程调整

- 幂等回执改为固定长度 `sha256` 摘要，不再保存完整命令载荷；
- 历史完整命令指纹在读取时等价压缩，重复命令仍保持同一幂等身份；
- 下一次成功正式命令会把压缩后的历史回执随快照原子持久化，不改变领域 Revision 或正式对象；
- 接口状态直接从本次已读取快照派生，不再重复解析整库；
- 文件存在性检查改用元数据访问，不再为判断备份是否存在而读取整个备份文件；
- 共享读取超时映射为 `SHARED_STORE_TIMEOUT / retry_safe`，前台只提示“已完成步骤不会丢失，请继续发布”，不再要求人工检查未知错误。
