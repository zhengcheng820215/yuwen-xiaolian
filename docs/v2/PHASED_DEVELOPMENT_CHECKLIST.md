# 轻舟 V2.0 分阶段开发清单

版本：V0.1（实施规划草案，不代表工程或产品验收通过）

适用范围：`轻舟V2.0` 转型副本
需求依据：[轻舟 V2.0 产品基线](./PRODUCT_BASELINE.md)

## 执行原则

以一道人为确认的真实现代文阅读主观错题为贯穿样本，每阶段交付可演示、可回归的纵向切片。先打通可信输入和可追溯证据，再扩展 AI 生成与评分；移动端、失败恢复和隐私控制贯穿各阶段，不留到最后补做。旧代码只作为候选资产，复用需通过接口、数据语义和质量验证，不把旧版工程通过视为 V2.0 验收。

阶段完成需同时满足本阶段功能、异常路径、移动端检查及自动化/人工验收。复测结果、长期能力画像和真实学习效果不得由工程测试自动推断。

## 阶段 0：范围冻结与技术基线

- [ ] 明确首版支持的现代文阅读主观题子类和不支持场景；给其他题型定义“识别/分类/存档”提示。
- [ ] 以真实错题建立覆盖清晰、模糊、多题、多图、无材料、无学生答案、批改混杂的验收样本集。
- [ ] 决定 OCR、诊断、生成、评分的服务边界、成本与失败策略；审计旧代码中可复用的诊断、题目、评分、会话能力。
- [ ] 确定学习记录 ID、阶段状态、版本与证据关联；确定图片/文本保留与删除规则。
- [ ] 给每阶段定义手机端验收设备、浏览器和 375–393 CSS px 视口检查方法。

**出口条件：** 范围、样本、状态模型和待确认决策有负责人可裁决的记录；不把示例数据误当真实学生证据。

## 阶段 1：错题输入、识别与人工确认

- [ ] 实现拍照优先与相册上传；拒绝摄像头权限后仍能上传。
- [ ] 支持裁剪、旋转、放大、重拍，以及阅读材料多图排序与确认。
- [ ] 识别题干、设问、选项/题号、关联材料、学生答案、批改信息及存在时的参考答案；允许修正识别文本并选择多题图片中的当前错题。
- [ ] 对缺失、模糊或无法区分的关键内容建立补图/手改/人工确认门禁；不编造阅读材料。
- [ ] 上传和 OCR 期间展示状态；失败后保留图片、排序和已修改文本，允许重试；图片按已确认策略压缩和受控保存。

**出口条件：** 用户可从真实图片得到一份已确认的 WrongQuestion；不满足诊断准入条件的记录不能进入个人错误诊断。手机端无横向滚动、按钮和键盘可用。

## 阶段 2：证据诊断与方法指导

- [ ] 将已确认的题目、材料和学生答案绑定为诊断输入；保留原图与确认文本的来源关系。
- [ ] 输出错误表现、具体证据、原因判断的确定程度、正确思路和可复用方法；从六类错误中选出本轮核心干预点。
- [ ] 同一错误可能由不同原因导致时，提供一次简短追加诊断；仍不确定则输出“原因暂不明确”。
- [ ] 诊断结果与原题、学生答案可对照，先展示结论和方法，再渐进展开分析。
- [ ] 用样本检查虚构引用、过度归因、无学生答案却作个人诊断，以及训练目标与诊断脱节。

**出口条件：** 每个进入训练的诊断都有可追溯证据和明确目标；不确定结果不会被伪装为确定性能力结论。

## 阶段 3：针对训练、题目质量与会话恢复

- [ ] 为同一目标能力点生成两道内容不同、难度可比的训练题，并在展示前校验材料、题干、答案和评分点的一致性。
- [ ] 生成合理答案范围、同义表达、常见错误及纠正方法；不合格题重生成或回退，不让学生作答。
- [ ] Training 1 支持分步引导；Training 2 默认独立，求助行为单独记录。
- [ ] 根据评分点反馈已满足、未满足、相对上一题变化和下一次注意点；保留原始答案、评分和提示记录。
- [ ] 一次重点展示一道题，阅读材料可快速定位；中途退出、刷新及网络失败后可恢复未完成会话。

**出口条件：** 两道题均可追溯到诊断目标，训练结束后会话数据完整；有提示的作答不会标为独立完成。

## 阶段 4：独立复测与三级评估

- [ ] 生成同目标能力点、难度相近但材料/问法不同的复测题；检查与训练题的内容独立性和答案泄漏风险。
- [ ] 复测期间隐藏提示、参考答案和可提前推知答案的反馈；记录独立作答与提交状态。
- [ ] 依据预设评分点、通过标准和目标关键项给出“初步掌握 / 尚未掌握 / 证据不足”。
- [ ] 对无效作答、题目质量问题、难度不可比或评分争议使用“证据不足”，不误判为退步。
- [ ] 结果页呈现原题问题、两次训练变化、复测证据及下一步建议；不报告无依据的精确提升百分比或稳定掌握。

**出口条件：** Retest 与 Evaluation 能反查原题、诊断、训练题版本、原始作答和评分依据；合理的不同表达可获得一致评价。

## 阶段 5：端到端产品验收与发布裁决

- [ ] 在主流手机浏览器上完成真实图片到结果评估的全流程，覆盖 375–393 CSS px 视口、刘海屏安全区和至少 44×44 CSS px 的建议触控目标。
- [ ] 覆盖摄像头拒权、模糊图、多图顺序、OCR 修正、AI 超时/失败、网络中断、键盘遮挡、退出恢复和重复提交。
- [ ] 对真实错题样本复核诊断证据、训练目标一致性、难度可比性、评分稳定性及复测独立性；记录争议与产品裁决。
- [ ] 核查图片及学生信息的压缩、访问、保留、删除和日志脱敏；确认不必要的数据不长期暴露。
- [ ] 对照产品基线的全部 MVP 条件逐项形成验收证据；单独裁决设计、工程、产品验收和上线状态。

**出口条件：** 仅当 MVP 条件均有证据且重大隐私/内容质量风险关闭，才可讨论受控试用或上线；工程构建成功不等于产品效果成立。

## 本轮不纳入首版开发

- 其他语文学科题型的完整个人诊断与训练闭环。
- 手写图片作答、复杂成长画像、跨时间“稳定掌握”判定。
- 用单次训练给出精确能力提升比例或长期能力升级承诺。
