# 素材资源录入平台 UX 校准记录

## 状态

`IMPLEMENTED / BUILD VERIFIED`

## 目标

本轮校准收敛素材资源录入平台与题目修改平台的信息层级、操作颜色、按钮尺寸、刷新交互和局部间距。调整只影响页面呈现与操作表达，不改变 Material、Observation Plan、Question Draft、Validation、Quality Assessment、Human Review、Freeze 或 Formal Resource 的正式契约。

## 信息层级

1. 顶栏只保留平台名称，删除不能帮助当前操作的副标题。
2. 删除训练任务“发布进度”步骤条。正式状态继续由任务检查、审核状态与发布结果表达，不再重复展示模拟流程。
3. 当前素材区只展示素材名称、自然段数量与素材级操作。
4. 待人工审核、发布未完成和已发布练习三个统计移动到“修改训练任务”标题区域，统计与其影响的工作区保持邻近。
5. 删除“素材内容”标题，正文直接承接当前素材信息。
6. 训练任务检查删除与右侧统计重复的辅助结论，只保留数量、检查结果、能力覆盖与训练方向。

## 间距与对齐

1. 主要纵向板块间距收敛为 `24px`。
2. “修改训练任务”标题、资源统计和版本提示之间分别使用 `16px` 间距。
3. 素材选择框到“当前素材”与素材级操作按钮的顶部距离均为 `24px`。
4. 素材名称信息结束到正文首段的距离为 `24px`。
5. 当前素材标题与操作按钮使用同一网格顶部基线；训练任务标题与三个资源统计保持水平居中。
6. 同组操作按钮间距统一为 `8px`，按钮宽度默认由文字和水平内边距决定，不无理由铺满容器。

## 文案与辅助信息

1. 删除适用学段、生成数量、训练方向和训练能力下方重复的辅助说明。
2. 可选规则合并到字段名称：`可选 2 项，默认由 AI 判断`，并使用辅助灰色。
3. 去重提示不再显示容易与当前计划任务数混淆的历史库存计数。
4. 已存在训练任务时统一说明：`再次生成时，系统会参考当前素材已有的训练任务，优先生成不同的训练内容。`
5. AI 预览的人工操作统一命名为“人工编辑校准”。

## 颜色与按钮

1. AI 生成、重新生成整组任务、生成更多任务和采用 AI 候选继续使用品牌紫语义。
2. 单任务候选的加载状态和内容对照表使用蓝色信息语义。
3. “人工编辑校准”使用 AI 次操作描边样式，与同组 AI 操作保持尺寸和间距一致。
4. “保留原内容”使用白底中性描边次按钮，不与生成或采用动作争夺主次。
5. 所有独立刷新入口统一使用 `RefreshIconButton`：`40px × 40px`、浅灰边框、白底、蓝色 Focus Ring、忙碌时旋转并禁用重复点击。

## 验收边界

- 页面刷新不会改变当前正式资源语义。
- 展开或收起素材正文不会修改 Material。
- 移动统计位置不会改变 Repository 计数口径。
- 删除辅助文案不会放宽生成、保存、审核或发布门禁。
- 重新生成候选仍需人工采用，采用前不创建新版本。
- Production Build 必须通过；现有 Bundle Size Warning 属于非阻断项。

## 跨平台页面身份加载

从素材资源录入平台打开题目修改、审核恢复或已发布题目时，目标平台必须先解析 Draft、Review、Freeze 与 Formal Resource 状态，再呈现对应页面身份。

1. 状态尚未解析时只显示中性的“正在载入题目”状态。
2. 加载期间不得先渲染“题目修改与提交平台”等默认业务身份。
3. 加载期间不得暴露编辑、审核、冻结或发布操作。
4. 已发布题目应在解析完成后直接进入“已发布题目”，不得产生看似重新审核或重新发布的视觉跳转。
5. 该加载门禁只影响页面呈现，不推进或回退任何正式生命周期状态。

## 本轮工程同步与验收

1. 训练任务生成操作统一命名为“重新生成整组任务”和“生成更多任务”，区分替换整组与增量补充两种动作。
2. 题目平台新增工作区加载门禁；Draft、Review、Freeze 与 Formal Resource 状态解析完成前，不渲染业务页面身份和正式操作。
3. 页面状态加载失败时显示中性失败页，不默认回退到题目修改状态。
4. 展示状态专项 Debug 共 `21/21` 项通过。
5. Production Build 通过；现有动态导入与 Bundle Size Warning 仍为非阻断项。
